# Первый запуск и учётная запись администратора

## Администратор создаётся автоматически {#admin-created}

Когда панель запускается, а база пользователей пуста, она создаёт одну учётную запись
администратора:

- Имя пользователя — `admin` (или значение `FORGE_ADMIN_USERNAME`).
- Если перед первым запуском задан `FORGE_ADMIN_PASSWORD`, пароль будет таким.
- Иначе **генерируется случайный пароль и один раз печатается в журнал**, вот так:

```text
============================================================
 FIRST-RUN ADMIN ACCOUNT CREATED
   username: admin
   password: <случайный пароль>
 This password is shown ONCE. Log in and change it now.
 (Set FORGE_ADMIN_USERNAME / FORGE_ADMIN_PASSWORD to choose
  your own credentials before first run.)
============================================================
```

Где найти журнал:

| Способ установки | Где журнал |
| --- | --- |
| Windows | окно Командной строки, где вы запустили `python main.py` |
| Linux / Raspberry Pi (systemd) | `sudo journalctl -u bambudiagnostic.service` |
| Docker | `docker compose logs` |

!!! note "Примечание"
    Пароль печатается только при том запуске, который создаёт учётную запись. `FORGE_ADMIN_USERNAME`
    и `FORGE_ADMIN_PASSWORD` тоже используются только тогда — если поменять их позже, существующие
    учётные записи не изменятся.

## Вход

Откройте адрес панели в браузере (`http://127.0.0.1:8000` на том же компьютере или адрес вашего
сервера). На странице входа — поля **«Логин»** и **«Пароль»** и кнопка **«Войти»**.

Сообщения об ошибках на странице входа приходят с сервера и пока на английском:

| Сообщение | Что значит |
| --- | --- |
| `Invalid username or password` | Неверный логин или пароль. |
| `Too many login attempts. Try again later.` | Слишком много неудачных попыток: 5 с одного адреса или 10 для одного логина за 15 минут. Подождите и попробуйте снова. |
| `Username and password required` | Не заполнено поле. |

Если после правильного входа страница снова просит пароль, браузер отбросил cookie входа — см.
[Вопросы и неполадки](../faq.md#login-loops).

## Сразу смените сгенерированный пароль

1. Откройте **«Админ → Доступ»**.
2. В таблице пользователей ваша строка отмечена «(вы)».
3. Нажмите **«Сменить пароль»**, введите новый пароль (не меньше 8 символов) и нажмите
   **«Сохранить»**.

Смена пароля завершает другие сеансы этого пользователя, поэтому может понадобиться войти заново.
