# Установка

Кузница — это одна программа (веб-сервер на Python). Её запускают на компьютере, который всегда
включён и находится в одной локальной сети с принтерами: Raspberry Pi, мини-ПК, домашний сервер.
Потом панель открывают в браузере на любом устройстве.

## Выберите способ установки

| Способ | Кому подходит | Страница |
| --- | --- | --- |
| **Docker** | Самый простой путь на Linux-сервере или NAS, где уже есть Docker. Рекомендован в README. | [Docker](docker.md) |
| **Linux / Raspberry Pi** с systemd | Постоянно включённый Raspberry Pi или Linux-компьютер: панель стартует при загрузке и сама перезапускается. | [Linux / Raspberry Pi](linux.md) |
| **Windows** | Попробовать панель на компьютере с Windows. | [Windows](windows.md) |

## Что понадобится

- **Компьютер** с Linux, macOS или Windows и **Python 3.11 или новее** — либо только Docker.
- **Сетевой доступ к каждому принтеру.** Панель сама подключается к принтерам, поэтому компьютер
  должен достучаться до IP-адреса каждого принтера по этим портам:

    | Принтер | Порт, к которому подключается панель |
    | --- | --- |
    | Bambu Lab | 8883 (пробуется и 8884) |
    | Creality | 9999 |
    | Klipper / Moonraker | 7125, если не указан другой |
    | MKS WiFi | 8080, если не указан другой |

    Проще всего держать компьютер и принтеры в одной сети (подсети / VLAN).
- **Интернет не обязателен.** Он нужен для Telegram (если включите) и раз в сутки — чтобы скачать
  с `e.bambulab.com` таблицы текстов ошибок и кнопок Bambu (отправляются только первые три символа
  серийного номера принтера). Без них панель берёт встроенные тексты.

## Где панель хранит данные

Всё хранится в файлах рядом с программой, в папке проекта:

| Файл / папка | Что внутри |
| --- | --- |
| `printer_history.db` | Список принтеров, настройки (Telegram, прокси, автоматика), история состояний, журнал печатей |
| `users.db` | Учётные записи, журнал действий, ключ, которым подписываются сеансы входа |
| `ams_history.db` | История влажности и температуры AMS |
| `data/hms/` | Скачанные тексты ошибок и кнопки Bambu (при отсутствии скачиваются заново) |

Чтобы сохранить настройки фермы и историю, делайте копии трёх файлов `.db`. Для Linux есть готовое
ночное резервное копирование — см. [Linux / Raspberry Pi](linux.md#backup).

## После установки

Перейдите к [первому запуску](first-run.md): узнайте пароль администратора, войдите и смените его,
затем [добавьте принтеры](../printers.md).
