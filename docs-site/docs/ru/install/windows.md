# Установка на Windows

На Windows панель запускается из исходного кода с помощью Python. В репозитории нет установщика для
Windows и нет готового автозапуска, поэтому этот способ подходит, чтобы попробовать панель, или для
компьютера, на котором вы держите открытым окно консоли.

## 1. Установите Python и Git

1. Установите **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/). В
   установщике поставьте галочку **«Add python.exe to PATH»**.
2. Установите **Git** с [git-scm.com](https://git-scm.com/download/win) — или скачайте репозиторий
   с GitHub архивом (**Code → Download ZIP**) и распакуйте.

## 2. Скачайте панель и её библиотеки

Откройте **Командную строку** (`cmd`) и выполните по очереди:

```bat
git clone https://github.com/mihey-web/printer-fleet-dashboard.git kuznitsa
cd kuznitsa
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Папка `.venv` — отдельная копия Python для панели, чтобы её библиотеки не смешивались с другими
программами.

## 3. Запустите

```bat
python main.py
```

В окне идёт журнал (лог). Не закрывайте его — закрытие окна останавливает панель. При самом первом
запуске в журнале один раз печатается пароль администратора; см. [Первый запуск](first-run.md).

Откройте <http://127.0.0.1:8000> в браузере на этом же компьютере.

## Как открыть панель с других устройств

По умолчанию панель слушает только этот компьютер (`127.0.0.1`) и ждёт HTTPS для cookie входа. Чтобы
открывать её с телефона или другого компьютера по обычному HTTP в локальной сети, задайте две
переменные **в том же окне перед запуском**:

```bat
set WEB_HOST=0.0.0.0
set COOKIE_SECURE=0
python main.py
```

Затем откройте `http://<IP-адрес этого компьютера>:8000`. Windows может спросить, разрешить ли
Python доступ через брандмауэр, — разрешите для частных сетей.

!!! warning "Обычный HTTP — только для доверенной домашней сети"
    `COOKIE_SECURE=0` передаёт cookie входа без шифрования. Не открывайте такую установку в
    интернет. См. [Пользователи и безопасность](../security.md).

!!! info "Или держите переменные в файле `.env`"
    Чтобы не набирать `set` каждый раз, скопируйте `.env.example` в `.env` в папке проекта и уберите
    `#` перед нужными строками (например, `WEB_HOST=0.0.0.0` и `COOKIE_SECURE=0`). `python main.py`
    читает `.env` при запуске; переменная, заданная командой `set` в окне, главнее. Все переменные —
    на странице [Настройки и переменные окружения](../configuration.md).

## Каждый следующий запуск

```bat
cd kuznitsa
.venv\Scripts\activate
python main.py
```

## «Применить и перезапустить» останавливает программу на Windows {#apply-restart-windows}

Когда вы меняете список принтеров, панель просит нажать **«Применить и перезапустить»**. Эта кнопка
завершает программу, чтобы диспетчер служб запустил её заново с новым списком. На Linux (systemd) и
в Docker это происходит само. **На Windows её никто не перезапустит** — после нажатия снова
выполните `python main.py` в окне.

## Обновление

```bat
cd kuznitsa
git pull
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Ваши данные (`printer_history.db`, `users.db`, `ams_history.db`) остаются в папке.
