# Экран «Админ»

Этот экран видят только администраторы. Это единственное место, где что-то настраивается для
всех. В нём четыре вкладки: **«Парк»**, **«Автоматика»**, **«Доступ»** и **«Система»**.

## «Парк»

Список принтеров — добавление, изменение и удаление, а также **«Применить и перезапустить»**.
Подробно — на странице [Добавление принтеров](../printers.md).

## «Автоматика»

### Автосушка AMS {#ams-auto-drying}

**«Автосушка AMS»** — правила задаются только здесь; **«Сушить все»** и **«Остановить все»** — на
[экране «AMS»](ams.md).

| Настройка | Что значит | По умолчанию |
| --- | --- | --- |
| **«Автосушка включена»** | Следит за блоками AMS и запускает сушку по правилам. Выключение не гасит уже идущие прогоны. | вкл |
| **«Пробный режим»** | Включён: автосушка только пишет журнал и ничего не отправляет принтерам. Выключен: сама запускает сушку. Кнопки **«Выключить…»** / **«Включить»**. | вкл |
| **«Держать влажность не выше»** | Цель, %. | 20 % |
| **«Повторять прогоны»** | Если после прогона всё ещё влажно: «пока не дойдёт до нужной», «один прогон» или «не больше 2 / 3 / 4 / 6 подряд». | не больше 2 подряд |
| **«Режим по умолчанию»** | **«Авто по пластику»** (для смеси — температура самого нежного пластика, время самого долгого), **«PLA 45° / 12 ч»**, **«PETG 65° / 12 ч»**, **«TPU 65° / 12 ч»** или **«Своё…»** (45–65 °C, 1–24 ч). Потолок AMS 2 Pro — 65 °C. | «Авто» |
| **«Сушить во время печати»** | Прошивка сама снизит температуру для печатающего AMS (PETG → 55°, PLA → 45°). | вкл |

В разделе **«Дополнительно»**:

| Настройка | Что значит | По умолчанию |
| --- | --- | --- |
| **«Не дёргаться от скачков»** | Запускать, только если влажно дольше этого времени (открыли крышку — влажность скачет и сама спадает). | 2 ч |
| **«Пауза между прогонами»** | Остывание, потом замер. | 1 ч |
| **«Окно запуска»** | «Любое время», «Ночью 22:00–08:00» или «Своё…». Вне окна старт ждёт; идущий прогон не прерывается. Время фермы — московское (UTC+3), если `FORGE_TZ_OFFSET_MIN` не задаёт другое. | любое время |
| **«После ручной остановки»** | Если сушку остановили в Handy, Bambu Studio или здесь, автосушка не трогает этот блок столько часов. | 24 ч |

С ограничением прогонов серия, не дошедшая до цели, повторяется не раньше чем через 48 ч; чужая
сушка тоже считается. Без ограничения сушит, пока не дойдёт до цели.

**«Блоки»** — таблица с переключателем **«Авто»** и **«Режимом»** для каждого блока: можно
исключить блок или дать ему свой режим.

**«Как это работает»** разворачивает объяснение цикла сушки — см.
[Экран «AMS»](ams.md#how-auto-drying-works).

Изменения сохраняются кнопкой **«Сохранить»**; **«Отменить правки»** их отбрасывает. Несохранённое
помечено «Есть несохранённые изменения».

### Автопропуск ошибок {#auto-skip-errors}

**«Автопропуск ошибок»** нажимает **«Игнорировать и продолжить»** на **всех принтерах Bambu**, когда
печать встала на паузу с одним из кодов из списка, — то же, что Bambu Studio отправляет для этой
кнопки. Нужен для пластин со стёртой меткой.

- Из коробки в списке **0500_8062** и **0C00_8009** — «не распознана метка на пластине». **Эти два
  кода действуют с первого запуска.** Уберите их, если это вам не нужно.
- Добавьте код вида `0500_8062` кнопкой **«+ код»**, уберите ненужный из списка и нажмите
  **«Сохранить»**. До 32 кодов. Рядом с каждым кодом — текст Bambu.
- Для каждой паузы повторяет попытку через 2 минуты, если пауза не ушла, не больше 3 раз. Принтеры
  на обслуживании пропускаются.
- **«Срабатывания ›»** открывает «История → Действия», группу «Автоматика», где записано каждое
  нажатие (и каждая непропущенная пауза с причиной).
