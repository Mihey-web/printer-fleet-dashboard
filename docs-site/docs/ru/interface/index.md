# Обзор интерфейса

В панели **четыре экрана**. Вкладки — в верхней строке на компьютере и в нижней панели на
телефоне.

| Экран | Что там | Кто видит |
| --- | --- | --- |
| [«Принтеры»](printers.md) | Карточки всех принтеров, строка фермы с фильтрами и командами на всю ферму, ближайшие финиши | все |
| [«AMS»](ams.md) | Влажность и температура каждого блока AMS, сушка, журнал автосушки | все |
| [«История»](history.md) | Печати, хронология, статистика и (администраторам) журнал действий | все |
| [«Админ»](admin.md) | Список принтеров, автоматика, пользователи, Telegram | только администраторы |

«Зритель» видит три экрана и не видит кнопок управления. О ролях — в разделе
[Пользователи и безопасность](../security.md).

## Верхняя строка

- **⚒ Кузница** — название панели.
- **Вкладки экранов.**
- **Колокольчик** — уведомления фермы. Когда принтеры требуют внимания, на нём «⚠ N»; нажмите,
  чтобы увидеть список. См. [Экран «Принтеры» → Уведомления](printers.md#printer-notifications).
- **Живая точка** со временем последнего обновления. Если сервер перестал отвечать, она краснеет и
  показывает, сколько нет связи (например, «нет связи · 2 мин»).
- **👤 и ваша роль** («Админ» или «Зритель») — открывает панель **«Этот браузер»**.

## Адрес страницы помнит, где вы

Текущий экран, вкладка «Истории», её период и принтер записаны в адресе страницы (например,
`#/history/jobs?period=7d`). Перезагрузка, кнопки браузера «Назад» / «Вперёд» и ссылка, которую вы
кому-то отправили, открывают то же самое.

## Панель «Этот браузер» (👤) {#this-browser}

Настройки здесь действуют **только в этом браузере** на этом устройстве, одинаково для обеих ролей:

| Раздел | Что делает |
| --- | --- |
| Ваш логин и **«Выйти»** | |
| **«Оформление»** | Тема: «Океан», «Классика», «Светлая», «Ночь», «Неон», «Космос». **«Масштаб текста»** 50–150 %. |
| **«Уведомления браузера»** | **«Всплывающие уведомления»** с галочками «завершение», «ошибка», «пауза». По умолчанию выключены; браузер спросит разрешение. |
| **«Приложение»** | **«Установить»** — появляется, только когда браузер предлагает поставить панель как приложение. См. [Телефон и приложение](mobile-pwa.md). |
| **«Версия»** | Работающая версия. |

!!! info "Уведомления браузера"
    Всплывающие уведомления показывает сама открытая страница панели: они работают, только пока
    панель открыта во вкладке, и **только по HTTPS** — по обычному HTTP панель пишет
    «Уведомления не работают через HTTP. Откройте https://…». Принтеры на обслуживании их не
    присылают. Чтобы получать оповещения при закрытом браузере, используйте [Telegram](../telegram.md).

## Подсказки и подтверждения

Наведите курсор на значок (на телефоне — коснитесь), чтобы увидеть подсказку. Команды, которые могут
навредить печати, — стоп, охлаждение на паузе, загрузка или выгрузка филамента, снятие с
обслуживания, удаление принтера — просят подтверждения прямо там, где вы нажали; вопрос без ответа
через несколько секунд исчезает сам. Ответ принтера показывается там же: «ждём принтер…», затем
«подтверждено», «отправлено, ответа нет» или ошибка.
