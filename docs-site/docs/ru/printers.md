# Добавление принтеров

Список принтеров («парк») хранится в базе панели и редактируется на веб-странице. Чтобы добавить,
изменить или удалить принтер, не нужно править файлы. Делать это может только администратор.

## Как добавить принтер

1. Откройте **«Админ → Парк»**.
2. Нажмите **«+ Добавить принтер»**.
3. Вверху формы выберите тип: **Bambu Lab**, **Creality**, **Klipper** или **MKS WiFi**. Форма
   покажет только нужные этому типу поля (см. ниже).
4. Нажмите **«Сохранить»**.
5. Появится полоса **«Есть непримененные изменения — N»**. Пока вы их не примените, панель
   опрашивает старый список. Нажмите **«Применить и перезапустить»** и подтвердите кнопкой
   **«Применить»**. Служба перезапустится — панель недоступна примерно 10 секунд, потом появится
   «Сервис перезапущен, конфигурация применена». Кнопка **«Отменить правки»** вместо этого
   отбрасывает неприменённые изменения списка.

!!! warning "Windows"
    «Применить и перезапустить» завершает программу и рассчитывает, что systemd или Docker
    запустят её снова. Если вы запускаете `python main.py` вручную на Windows, после нажатия
    запустите её сами. См. [Windows](install/windows.md#apply-restart-windows).

В той же таблице в каждой строке есть **«Изменить»** и **«Удалить»**. У удалённого принтера история
печати сохраняется; пока изменения не применены, его можно вернуть кнопкой **«Вернуть»**. История
привязана к внутреннему ID, поэтому при переименовании принтера она не теряется.

Сервер проверяет форму: **«Название»** и **«IP-адрес»** не могут быть пустыми, порт — от 1 до 65535,
а для Bambu обязательны код доступа и серийный номер.

## Bambu Lab

| Поле | Что вводить |
| --- | --- |
| **«Название»** | Любое имя, например `P1S-1`. |
| **«Модель»** | Выберите из списка: X1, X1 Carbon, X1E, P1P, P1S, P2S, A1, A1 mini, H2D, H2S. |
| **«IP-адрес»** | Адрес принтера в вашей сети. |
| **«Код доступа»** | Код с экрана принтера. Подсказка под полем: «Экран принтера → Настройки → Сеть». Кнопка 👁 показывает введённое. |
| **«Серийный номер»** | Серийный номер принтера. |

Что нужно от принтера:

- **Режим LAN.** README требует, чтобы принтер был в режиме LAN (LAN Mode). Панель подключается к
  MQTT-серверу самого принтера по TLS (порт 8883; пробуется и 8884) с кодом доступа. Облачная
  учётная запись Bambu не используется.
- **Для управления может понадобиться Developer Mode.** Для наблюдения хватает кода доступа. Для
  паузы, продолжения, стопа, охлаждения, опускания стола, температур, вентиляторов, скорости и
  команд AMS принтер должен принимать команды без подписи Bambu. Панель проверяет это сама; новые
  прошивки принимают такие команды только в Developer Mode. Если принтер их отвергает, на карточке
  остаётся только кнопка света и замок с причиной «прошивка блокирует (нет Developer Mode)». Пока
  проверка идёт, причина — «доступ к управлению ещё проверяется».
- По желанию панель может проверять TLS-сертификат принтера — см. `FORGE_BAMBU_TLS_VERIFY` в
  [Настройках](configuration.md).

Из коробки Кузница сама нажимает «Игнорировать и продолжить» на двух ошибках печати Bambu (не
распознана метка на пластине). См. [«Админ → Автоматика»](interface/admin.md#auto-skip-errors).

## Creality

| Поле | Что вводить |
| --- | --- |
| **«Название»** | Любое имя. |
| **«Модель»** | K1 Max, K1C или Ender-5 Max. |
| **«IP-адрес»** | Адрес принтера в вашей сети. |
| **«Разрешить управление светом»** | Включено по умолчанию. Выключите для принтера без управляемой лампы: его кнопка 💡 и «Свет» фермы будут его пропускать. Эта галочка сохраняется сразу, без перезапуска. |

Панель подключается к WebSocket принтера на порту **9999**; пароль или код не нужны. Для Creality
карточка предлагает паузу / продолжение / стоп, свет, охлаждение, температуры сопла и стола, режимы
скорости и вентиляторы. Creality никогда не подтверждает команду, поэтому результат —
«отправлено», а не «подтверждено».

## Klipper / Moonraker

| Поле | Что вводить |
| --- | --- |
| **«Название»** | Любое имя. |
| **«Модель (не обязательно)»** | Произвольный текст, можно оставить пустым. |
| **«IP-адрес»** | Адрес компьютера, где работает Moonraker (хост принтера). |
| **«Порт»** | Порт Moonraker. Оставьте пустым — будет **7125**. |

Панель подключается к `ws://<IP>:<порт>/websocket`. Поля для API-ключа в форме нет, поэтому
Moonraker должен пускать компьютер с панелью без ключа.

Для Klipper карточка предлагает паузу / продолжение / отмену, когда Klipper сообщает о готовности,
и кнопку света, если у принтера есть свет: панель ищет `output_pin` с именем `caselight` /
`case_light`, затем со словом `light`, затем `led`, затем `lamp`. Если Klipper остановился
(например, «mcu: Unable to connect»), принтер остаётся онлайн в состоянии ошибки с причиной и
предлагает «Перезапуск прошивки».

## MKS WiFi

| Поле | Что вводить |
| --- | --- |
| **«Название»** | Любое имя. |
| **«Модель (не обязательно)»** | Произвольный текст, можно оставить пустым. |
| **«IP-адрес»** | Адрес модуля MKS WiFi. |
| **«Порт»** | Оставьте пустым — будет **8080**. |

Панель открывает TCP-соединение с модулем и читает состояние G-кодами (M115, M997, M27, M105,
M114, M220, затем M991, M992, M994). **Принтеры MKS — только наблюдение**: кнопок управления на
их карточке нет.

## Как узнать IP-адрес принтера

Каждый принтер показывает свой IP-адрес в сетевых настройках; его видно и в списке подключённых
устройств роутера. Закрепите за принтерами постоянные адреса (резервирование DHCP в роутере), чтобы
адрес в панели оставался верным.

## Столбцы таблицы «Парк»

**«Название»**, **«Модель»**, **«Тип»**, **«IP»**, **«Прошивка»**, **«Обслуживание»**,
**«Управление»** (только просмотр — что панель может делать с этим принтером), **«Действия»**.
Режим обслуживания включается на карточке принтера, а не здесь — см.
[Экран «Принтеры»](interface/printers.md#maintenance-mode).
