# Добавление принтеров

Список принтеров («парк») хранится в базе панели и редактируется на веб-странице. Чтобы добавить,
изменить или удалить принтер, не нужно править файлы. Делать это может только администратор.

## Как добавить принтер

1. Откройте **«Админ → Парк»**.
2. Нажмите **«+ Добавить принтер»**.
3. Вверху формы выберите тип: **Bambu Lab**, **Creality**, **Klipper** или **MKS WiFi**. Форма
   покажет только нужные этому типу поля (см. ниже).
4. Нажмите **«Сохранить»**.
5. Появится полоса **«Есть непримененные изменения — N»**. Пока вы их не примените, панель
   опрашивает старый список. Нажмите **«Применить и перезапустить»** и подтвердите кнопкой
   **«Применить»**. Служба перезапустится — панель недоступна примерно 10 секунд, потом появится
   «Сервис перезапущен, конфигурация применена». Кнопка **«Отменить правки»** вместо этого
   отбрасывает неприменённые изменения списка.

!!! warning "Windows"
    «Применить и перезапустить» завершает программу и рассчитывает, что systemd или Docker
    запустят её снова. Если вы запускаете `python main.py` вручную на Windows, после нажатия
    запустите её сами. См. [Windows](install/windows.md#apply-restart-windows).

В той же таблице в каждой строке есть **«Изменить»** и **«Удалить»**. У удалённого принтера история
печати сохраняется; пока изменения не применены, его можно вернуть кнопкой **«Вернуть»**. История
привязана к внутреннему ID, поэтому при переименовании принтера она не теряется.

Сервер проверяет форму: **«Название»** и **«IP-адрес»** не могут быть пустыми, порт — от 1 до 65535,
а для Bambu обязательны код доступа и серийный номер.

## Bambu Lab

| Поле | Что вводить |
| --- | --- |
| **«Название»** | Любое имя, например `P1S-1`. |
| **«Модель»** | Выберите из списка: X1, X1 Carbon, X1E, P1P, P1S, P2S, A1, A1 mini, A2L, H2C, H2D, H2D Pro, H2S, X2D. |
| **«IP-адрес»** | Адрес принтера в вашей сети. |
| **«Код доступа»** | Код с экрана принтера. Подсказка под полем: «Экран принтера → Настройки → Сеть». Кнопка 👁 показывает введённое. |
| **«Серийный номер»** | Серийный номер принтера. |

Что нужно от принтера:

- **Режим LAN.** README требует, чтобы принтер был в режиме LAN (LAN Mode). Панель подключается к
  MQTT-серверу самого принтера по TLS (порт 8883; пробуется и 8884) с кодом доступа. Облачная
  учётная запись Bambu не используется.
- **Для управления может понадобиться Developer Mode.** Для наблюдения хватает кода доступа. Для
  паузы, продолжения, стопа, охлаждения, опускания стола, температур, вентиляторов, скорости и
  команд AMS принтер должен принимать команды без подписи Bambu. Панель проверяет это сама; новые
  прошивки принимают такие команды только в Developer Mode. Если принтер их отвергает, на карточке
  остаётся только кнопка света и замок с причиной «прошивка блокирует (нет Developer Mode)». Пока
  проверка идёт, причина — «доступ к управлению ещё проверяется».
- По желанию панель может проверять TLS-сертификат принтера — см. `FORGE_BAMBU_TLS_VERIFY` в
  [Настройках](configuration.md).

Из коробки Кузница сама нажимает «Игнорировать и продолжить» на двух ошибках печати Bambu (не
распознана метка на пластине). См. [«Админ → Автоматика»](interface/admin.md#auto-skip-errors).

Что зависит от модели Bambu:

| | X1 | P1, A1 | P2S, серия H2, X2D |
| --- | --- | --- | --- |
| [Карточка задания](interface/printers.md#where-the-job-card-comes-from) | из памяти принтера; настройки печати — если файл задания лежит на SD-карте | с SD-карты | из памяти принтера; настройки печати — если файл задания лежит на флешке |
| [Файлы на принтере](interface/printers.md#files-on-the-printer) | видны и запускаются | SD-карта: видны и запускаются | внутренняя память видна, но запускается только с экрана принтера; флешка видна и запускается. H2S внутреннюю память не открывает — только флешка |
| [Общие файлы](interface/shared-files.md) | источник и получатель (нужна SD-карта) | источник и получатель (нужна SD-карта) | источник и получатель только через флешку |
| Режим воздуховода | — | — | P2S и серия H2 ([окно вентиляторов](interface/printers.md#air-duct)) |
| Нагрев камеры | — | — | серия H2 |

Запуску файла, как и любой команде печати, нужен Developer Mode. Принтеры с двумя соплами (H2D,
H2C, X2D) пока не запускают файлы из панели и не загружают / не выгружают филамент AMS. Чтобы
[пропускать детали на ходу](interface/printers.md#skip-parts), задание должно быть нарезано с
включённой маркировкой деталей.

## Creality

| Поле | Что вводить |
| --- | --- |
| **«Название»** | Любое имя. |
| **«Модель»** | Выберите K1, K1 Max, K1C, K1 SE, K2, K2 Plus, K2 Pro, K2 SE, Ender-3 V3, Ender-3 V3 KE, Ender-3 V3 Plus, Ender-5 Max, CR-10 SE, Hi, SPARKX i7 или введите свою модель. Для мониторинга принтер должен передавать совместимые данные на порту 9999. |
| **«IP-адрес»** | Адрес принтера в вашей сети. |
| **«Разрешить управление светом»** | Включено по умолчанию. Выключите для принтера без управляемой лампы: его кнопка 💡 и «Свет» фермы будут его пропускать. Эта галочка сохраняется сразу, без перезапуска. |

Панель подключается к WebSocket принтера на порту **9999**; пароль или код не нужны. Для этого
используется отдельный клиент, скопированный из
[ha_creality_ws](https://github.com/3dg1luk43/ha_creality_ws) (AGPL-3.0, в
`app/vendor/ha_creality_ws`). Для Creality карточка предлагает:

- паузу / продолжение / стоп, свет, охлаждение, режимы скорости и вентиляторы;
- температуры сопла и стола до пределов модели: 350 / 120 °C у K2 Plus, 300 / 100 °C у K1, K1C,
  K1 SE, K1 Max и Ender-5 Max; у остальных моделей — до того, что сообщает принтер;
- температуру камеры, если принтер её сообщает, и нагрев камеры у K2 Plus / K2 Pro, которые
  сообщают цель камеры;
- **опустить стол** у K1, K1C, K1 Max, K2 Plus и Ender-5 Max — после того как найдены нули осей
  (иначе «Сначала выполните «Домой»»);
- **«Домой»** и **сдвиг осей** ([окно перемещения](interface/printers.md#motion)) собственными
  командами прошивки — теми же, что шлёт Creality Print. Подачи и втягивания прутка у Creality нет —
  только с экрана принтера;
- **CFS**: слоты с материалом и остатком, влажность и температура, загрузка / выгрузка, чтение
  метки, катушка вручную и настройка запасной катушки ([CFS у Creality](interface/printers.md#creality-cfs));
- **файлы на принтере** с запуском печати ([Файлы на принтере](interface/printers.md#files-on-the-printer))
  и [карточку задания](interface/printers.md#where-the-job-card-comes-from) из списка файлов
  принтера;
- **пропуск деталей** во время печати, где принтер сообщает детали задания (K2 Plus, K1C, Ender-5
  Max) — см. [Пропуск деталей](interface/printers.md#skip-parts);
- код ошибки в уведомлении с кнопкой **«Сбросить ошибку»** или **«Перезапустить прошивку»** — см.
  [Уведомления принтеров](interface/printers.md#printer-notifications).

Большинство команд Creality не подтверждает, поэтому их результат — «отправлено», а не
«подтверждено». Исключение — свет: он подтверждается, как только принтер сообщит новое состояние
лампы.

### K2 Plus: Klipper API {#k2-plus}

Некоторые Creality, например K2 Plus, работают ещё и через Klipper API (Moonraker) на порту
**7125**. Панель находит его сама, в форме ничего задавать не нужно, но Moonraker должен пускать
компьютер с панелью без API-ключа. У K1C и Ender-5 Max такого API нет. Через него:

- **файлы на принтере** видны с картинками, временем и граммами, их можно удалять (**«Удалить с
  принтера»**), и K2 Plus становится источником и получателем [общих файлов по
  моделям](interface/shared-files.md) без флешки;
- **карточка задания** получает и настройки печати из G-кода задания: высоту слоя, заполнение,
  стенки, поддержки и их вес, стол, профили пластиков и версию слайсера;
- в уведомлении о паузе появляется **«Продолжить печать»**;
- **⋯ → «Сервис ›»** запускает калибровки принтера и перезапуск прошивки — см.
  [«Сервис»](interface/printers.md#k2-service).

### Ender-5 Max {#ender-5-max}

- **Вес по длине.** Его список файлов даёт длину прутка, а не вес. Панель считает вес сама: длина ×
  сечение прутка 1,75 мм × плотность материала (те же, что у Creality Print: PLA 1,24, PETG 1,27,
  ABS 1,04, ASA 1,07, TPU 1,21, PC 1,20 г/см³). Материал берётся из имени файла, как его пишет
  Creality Print, например `Кронштейн_PETG_2h5m.gcode`; если в имени его нет — считается PETG.
  Поэтому вес на карточке и во [«Истории → Пластик»](interface/history.md#plastic) близок к весу из
  слайсера, но не точен.
- **Карточка задания:** только картинка и этот вес — настроек печати в его списке файлов нет.
- **Вентиляторы:** обдув детали и корпуса только включается или выключается; вспомогательного
  вентилятора нет.
- **Опустить стол** — только после того, как найдены нули осей; **«Домой»** — собственная команда
  прошивки.

## Klipper / Moonraker

| Поле | Что вводить |
| --- | --- |
| **«Название»** | Любое имя. |
| **«Модель (не обязательно)»** | Произвольный текст, можно оставить пустым. |
| **«IP-адрес»** | Адрес компьютера, где работает Moonraker (хост принтера). |
| **«Порт»** | Порт Moonraker. Оставьте пустым — будет **7125**. |

Панель подключается к `ws://<IP>:<порт>/websocket`. Поля для API-ключа в форме нет, поэтому
Moonraker должен пускать компьютер с панелью без ключа.

Для Klipper карточка предлагает паузу / продолжение / отмену и [окно
перемещения](interface/printers.md#motion) («Домой», сдвиг осей, подача / втягивание прутка), когда
Klipper сообщает о готовности, и кнопку света, если у принтера есть свет: панель ищет `output_pin`
с именем `caselight` /
`case_light`, затем со словом `light`, затем `led`, затем `lamp`. Если Klipper остановился
(например, «mcu: Unable to connect»), принтер остаётся онлайн в состоянии ошибки с причиной и
предлагает «Перезапуск прошивки».

## MKS WiFi

| Поле | Что вводить |
| --- | --- |
| **«Название»** | Любое имя. |
| **«Модель (не обязательно)»** | Произвольный текст, можно оставить пустым. |
| **«IP-адрес»** | Адрес модуля MKS WiFi. |
| **«Порт»** | Оставьте пустым — будет **8080**. |

Панель открывает TCP-соединение с модулем и читает состояние G-кодами (M115, M997, M27, M105,
M114, M220, затем M991, M992, M994). **Принтеры MKS — только наблюдение**: кнопок управления на
их карточке нет.

## Как узнать IP-адрес принтера

Каждый принтер показывает свой IP-адрес в сетевых настройках; его видно и в списке подключённых
устройств роутера. Закрепите за принтерами постоянные адреса (резервирование DHCP в роутере), чтобы
адрес в панели оставался верным.

## Столбцы таблицы «Парк»

**«Название»**, **«Модель»**, **«Тип»**, **«IP»**, **«Прошивка»**, **«Обслуживание»**,
**«Управление»** (только просмотр — что панель может делать с этим принтером), **«Действия»**.
Режим обслуживания включается на карточке принтера, а не здесь — см.
[Экран «Принтеры»](interface/printers.md#maintenance-mode).
