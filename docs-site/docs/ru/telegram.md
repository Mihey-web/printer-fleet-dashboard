# Уведомления в Telegram и прокси

Кузница может запустить Telegram-бота, который держит в вашем чате живую сводку по ферме и пишет,
когда печать завершилась, встала на паузу или упала в ошибку. По умолчанию бот выключен. Всё
настраивается на веб-странице — токен, чат и прокси хранятся в базе панели, а не в файлах.

## 1. Создайте бота

1. В Telegram откройте **@BotFather** и отправьте `/newbot`.
2. Придумайте боту имя и имя пользователя.
3. BotFather ответит **токеном** (длинная строка с двоеточием). Никому его не показывайте.

## 2. Введите токен

1. Откройте **«Админ → Система»**, раздел **Telegram**.
2. Включите **«Телеграм-бот»**.
3. Разверните **«Токен, чат, шаблоны и прокси»**.
4. Вставьте токен в поле **«Токен бота»**. Смена токена перезапускает бота.

Настройки этого раздела сохраняются на лету (появляется отметка «Сохранено») — перезапуск не
нужен.

## 3. Разрешите свой чат

Поле **«Разрешённый ID чата»** — номер чата Telegram, с которым работает бот.

!!! warning "Заполните ID чата — без него бот не работает"
    Подсказка под полем говорит, что пустое поле — «без ограничения», но в версии 2.0.0 бот
    отвечает на `/start` **только** из чата, чей ID здесь указан. При пустом поле отклоняется любой
    чат и уведомления не отправляются.

Как узнать ID своего чата с помощью самой панели:

1. Когда токен введён и бот включён, откройте своего бота в Telegram и отправьте `/start`.
2. Бот отклонит незнакомый чат и запишет его номер в журнал панели: `Denied chat 123456789`.
3. Введите это число в **«Разрешённый ID чата»**.
4. Снова отправьте `/start`.

Где журнал — см. [Первый запуск](install/first-run.md#admin-created).

## 4. Живая сводка

После `/start` бот присылает сообщение с состоянием каждого принтера и **редактирует это же
сообщение** каждые **«Интервал обновления, сек»** (по умолчанию 2, от 1 до 3600). Каждый новый
`/start` присылает свежее сообщение. Закрепить его в чате можно самостоятельно.

Порядок принтеров в сводке: ошибки, паузы, завершённые, печатающие (сначала ближайший финиш),
простаивающие, остальные; принтеры на обслуживании — в конце. Например:

```text
🔴 K1C — ошибка: <текст ошибки принтера>
🟡 X1C — 80% · case
✅ A1 mini — завершено · clip
🟢 P1S-1 — 47% · bracket x4
⏱2ч10м · ⏳1ч55м · 🌡220/60°C
⬛ Ghost — офлайн
🔧 H2D — на обслуживании
```

⏱ — сколько осталось, ⏳ — сколько уже печатается, 🌡 — сопло / стол.

**«Язык бота»** переключает бота на английский: сводку (`— offline`, `⏱2h10m`), тексты ошибок
Bambu (английский оригинал по коду) и шаблоны по умолчанию. Шаблон, который вы написали сами,
бот шлёт как написан.

## 5. Уведомления о событиях

В блоке **«Уведомления о событиях»** у каждого события свой переключатель и шаблон сообщения:

| Событие | Шаблон по умолчанию | Когда отправляется |
| --- | --- | --- |
| **«Завершение печати»** | `✅ Печать завершена: {label}` | принтер перешёл из печати в «завершено» |
| └ **«Повторять, пока не забрали»** | — | пока принтер стоит завершённым, повторять каждые **N** минут («Интервал повтора, мин», по умолчанию 30, от 1 до 1440) |
| **«Ошибка принтера»** | `🔴 Ошибка: {label}` | принтер ушёл в ошибку; добавляется текст ошибки принтера |
| **«Пауза печати»** | `⚠️ Пауза: {label}` | печатающий принтер встал на паузу |

- Все три события по умолчанию **выключены**; повтор включён, поэтому заработает, как только вы
  включите «Завершение печати».
- `{label}` заменяется именем принтера. Это единственная подстановка — любая другая `{...}`
  отклоняется. Сообщения отправляются с HTML-разметкой Telegram, поэтому в шаблоне можно
  использовать теги вроде `<b>…</b>`.
- Принтеры на обслуживании ничего не присылают.

## 6. Прокси для Telegram {#proxy}

Если Telegram в вашей сети заблокирован, добавьте прокси в блоке **«Прокси для Telegram»**. Блок
виден, только пока бот включён.

- Введите адрес вида `http://логин:пароль@хост:порт` и нажмите **«+ Добавить»**. Принимаются только
  прокси `http://` и `https://`; логин и пароль не обязательны.
- Если в логине или пароле есть `/`, `?`, `#` или `@`, запишите их в закодированном виде: `%2F`,
  `%3F`, `%23`, `%40`.
- Каждый прокси регулярно проверяется запросом к `api.telegram.org`; в таблице — **«Адрес»**,
  **«Статус»** и **«Задержка»**. Бот всегда ходит через самый быстрый рабочий прокси и
  переключается автоматически.
- **«Интервал проверки, сек»** — по умолчанию 600, от 30 до 86400. **«Проверить сейчас»** проверяет
  сразу; **«Последняя проверка»** показывает когда.
- Если список прокси пуст, бот подключается к Telegram напрямую.
- Логины и пароли прокси в журналах панели скрываются.

## Если бот молчит {#bot-silent}

- Включён ли **«Телеграм-бот»** и верен ли токен? При старте бота в журнале появляется
  `Telegram bot started`.
- Заполнен ли **«Разрешённый ID чата»** номером вашего чата (см. шаг 3)?
- Отправляли ли вы боту `/start` хотя бы раз? Telegram не даёт боту писать тому, кто его ни разу не
  запускал.
- Есть ли у компьютера с панелью доступ к `api.telegram.org`? Если нет — добавьте прокси.
