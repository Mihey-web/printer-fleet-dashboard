### Т1. Нестабильные тесты MQTT — ошибка тестового брокера, не продукта

`tests/bambu_testkit.py:266`, `:287`, а также `SO_REUSEADDR` в конструкторе `StubBroker`.

На Linux `socket.close()` из другого потока не будит поток, который висит в `recv()` или `accept()`. FIN не уходит, клиент не видит обрыва, а слушающий сокет держит порт. Поэтому `test_back_online_within_seconds_after_a_reboot` и `test_back_online_after_refused_then_off_then_on` падали: первый на таймингах или «не заметил обрыв», второй на `EADDRINUSE`. Код продукта ни при чём.

Перед `close()` добавлен `shutdown(SHUT_RDWR)`. `SO_REUSEADDR` теперь ставится и первому брокеру: Linux даёт занять порт заново, только если флаг есть у всех сокетов, ещё держащих порт. Проверено тремя прогонами подряд. Логика тестов и их ожидания не менялись.

## README обещает то, чего в коде нет

- **`.env`.** README («From source»): `cp .env.example .env # optional`. Код `.env` не читает нигде, `python-dotenv` в зависимостях нет. Кто положит `FORGE_ADMIN_PASSWORD` или `COOKIE_SECURE=0` в `.env` и запустит `python main.py`, получит случайный пароль. Без HTTPS вход ещё и «молча» не работает: cookie с флагом Secure браузер по HTTP не хранит. Переменные работают только через окружение процесса (systemd `Environment=`, `docker compose`).
- **Тесты.** «Running the tests: `pip install pytest`» — нужен ещё `httpx`, иначе 11 файлов не собираются.
- **Docker: «Databases persist in the repo directory».** В `docker-compose.yml` смонтированы только `printer_history.db` и `users.db`. `ams_history.db` (история влажности AMS; на ней работает автосушка) живёт внутри контейнера и пропадает при `docker compose up --build`.
- **«click Apply to restart the poller».** `POST /api/admin/printers/apply` делает `os._exit(1)` и рассчитывает, что процесс поднимет systemd или Docker. При запуске `python main.py` из раздела «From source» без них панель просто останавливается.
- **Docker и SECURITY.md.** SECURITY.md: «never directly on the public internet», «keep `COOKIE_SECURE=1`». `docker-compose.yml` публикует порт 8000 на всех интерфейсах с `COOKIE_SECURE=0`, а Docker обходит правила ufw. Для LAN это задумано, но стоит одной строкой предупредить в README.
- **«login rate limiting».** Есть по IP. Блокировка по имени пользователя от подбора не защищает (см. выше).

## Что проверено и в порядке

- **SQL.** Все запросы с параметрами `?`. Динамические куски SQL (`%s` в `_query_events` и `_query_timeline`, `WHERE` в `audit_service`, колонки в `job_queries`) собираются только из фиксированных литералов и белых списков.
- **JWT.** `HS256` задан явно, тип токена (`access` / `refresh`) проверяется, refresh одноразовый (атомарный `INSERT OR IGNORE`). Удалённый пользователь и сброс пароля закрывают сессию на каждом запросе. Секрет не в коде: окружение, потом `users.db`, иначе генерируется. Первый пароль admin случайный и пишется в лог один раз.
- **Роли.** Все `/api/admin/*` закрыты в middleware. `/api/debug/printers/*` и CSV журнала проверяют роль сами. Путь для проверки берётся из `scope`, а не из `request.url`, поэтому подмена Host и `..` в `/static` не открывают закрытое (на это есть тесты). Cookie `HttpOnly` и `SameSite=Strict`.
- **Секреты.** Код доступа Bambu, токен Telegram и пароли прокси отдаются только в `/api/admin/*`. В аудит пишутся только имена изменённых ключей. Учётные данные прокси маскируются в логах, и в трейсбэках тоже.
- **XSS.** Все 58 мест `innerHTML` в `app.js` получают строки от принтера (имена, задания, тексты HMS и Klipper, user agent) через `safeText` / `escHtml`. Ссылки на wiki только `https://`, цвета через регулярку. Service worker кэширует только `/static/*` и чистит кэш при выходе.
- **Шаблоны Telegram.** Подставляется только `{label}`, с HTML-экранированием; бот отвечает только разрешённому `chat_id`.
- **G-code.** Строки собираются только из проверенных целых. Имя пина Klipper проходит белый список `[A-Za-z0-9_]`, пресет сушки берётся из списка, ключ уведомления проверяется `fullmatch`. MKS к API команд не подключён.
- **Падения на телеметрии Bambu.** Прогон с подстановкой None, чисел, строк, списков, NaN, `10**30` во все поля фикстур X1C / H2S / P1S: кроме f4 и f5, ничего не вылетает из `on_message` и `normalize_bambu`.
- **Переподключения.** Bambu: listener, watchdog и `close()`; Creality и Klipper: `_connect_lock`, `join` старого потока. Повторяемой гонки не нашлось (одно теоретическое место — в таблице выше). Кэши и словари трекеров ограничены по размеру.
